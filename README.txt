BREW & BEAN — 3D COFFEE HOUSE WEBSITE

FILES
- index.html: complete single-page website
- style.css: responsive styling, 3D effects and animations
- script.js: mobile navigation and interactive card tilt
- images/image_sources.txt: real photo source links used by the website
- video/README.txt: note about the video section

HOW TO OPEN
1. Extract this ZIP.
2. Open the extracted brew_and_bean_website folder.
3. Double-click index.html to preview in your browser.
4. Keep the folder structure unchanged.

IMPORTANT ABOUT PHOTOS
The website uses real café/coffee photographs hosted by Unsplash (images.unsplash.com). The photos load from the internet, so an internet connection is needed to display them. The ZIP contains the website code and source links, not copied image files.

BEFORE PUBLISHING
- Replace the sample address, phone number and opening hours in index.html.
- Update the sample menu prices to your real prices.
- The video panel is currently a photographic feature panel, not a playable video. Add your own MP4 file and video tag if you want an actual video.

GITHUB PAGES
Upload index.html, style.css, script.js, images/ and video/ to the root of your coffee-shop GitHub repository. Then open Settings > Pages and publish from the main branch, root folder.

The former video section has been replaced with a featured coffee photograph supplied by the website owner. All photos are stored locally in the images folder.
